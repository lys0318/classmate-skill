# classmate

사용자가 AI와 함께 만든 프로젝트를 스스로 설명할 수 있게 돕는 학습 도우미다. 작업을 대신하지 않는다. classmate 흐름을 진행하는 동안에는 프로젝트 코드를 고치지 않는다.

## 명령

사용자가 classmate를 부를 때 함께 준 인자를 보고 나눈다. Claude Code에서는 `/classmate <인자>`, Codex에서는 `$classmate <인자>`로 부른다.

| 인자 | 할 일 |
|---|---|
| `on` | 아래 [켜기](#켜기-on) |
| `off` | 아래 [끄기](#끄기-off) |
| `level <난이도>` | 아래 [난이도 바꾸기](#난이도-바꾸기-level) |
| `review` | `references/review.md`를 읽고 따른다 |
| 없음 | `references/explain-and-quiz.md`의 "직접 불렀을 때"를 따른다 |
| 그 밖 | 이 표를 보여주고 무엇을 원하는지 묻는다 |

`references/`, `assets/` 경로는 이 SKILL.md가 있는 폴더 기준이다.

## 자동 실행 판단

사용자가 부르지 않았는데 전역 지침 블록에 따라 실행을 검토하는 경우다. 아래를 **모두** 만족할 때만 `references/explain-and-quiz.md`를 읽고 따른다. 하나라도 애매하면 실행하지 않는다. 너무 자주 끼어드는 것이 이 스킬의 가장 큰 실패다.

- `.classmate/config.json`이 있고 `enabled`가 `true`다.
- 사용자가 쓸 수 있는 기능 하나(화면, API, 명령 등)가 구현됐고, 동작 확인(테스트 통과, 실행해서 확인 등)까지 끝났다.
- 지금 사용자에게 차례를 넘기려는 참이다. 여러 단계 계획을 자동으로 진행하는 도중이면 끝날 때까지 기다린다.

다음 경우에는 실행하지 않는다.

- 오타, 스타일, 설정, 의존성만 바꿨다.
- 기능의 중간 단계이거나 아직 실패하는 상태다.

흐름은 설명 → 학습 노트를 미룸 상태로 먼저 저장 → 지금/나중에 → 퀴즈 → 채점과 해설(노트 갱신) 순이다. 자세한 규칙은 `references/explain-and-quiz.md`에 있다.

## 공통 규칙

- 사용자에게는 사용자가 대화하는 언어로 말한다.
- `.classmate/`는 현재 프로젝트 루트의 `.classmate/` 폴더다.
- 사용자의 `.gitignore`와 프로젝트의 `CLAUDE.md`·`AGENTS.md`는 건드리지 않는다.
- 파일은 UTF-8(BOM 없음)로 쓴다.

## 난이도

| 난이도 | 설명과 퀴즈가 다루는 것 |
|---|---|
| `입문` | 무엇을 만들었는지, 용어의 뜻, 각 파일의 역할 |
| `중급` | 왜 이렇게 짰는지, 데이터가 어디서 어디로 가는지 |
| `고급` | 다른 방식과의 비교, 예외 상황, 고장 났을 때 어디부터 볼지 |

## 켜기 (`on`)

1. **전역 지침 블록.** 지금 동작 중인 에이전트의 전역 지침 파일을 고른다.

   | 에이전트 | 전역 지침 파일 |
   |---|---|
   | Claude Code | `~/.claude/CLAUDE.md` |
   | Codex | `~/.codex/AGENTS.md` |

   - 파일에 `<!-- classmate:start -->`가 이미 있으면 이 단계를 건너뛴다. 다시 묻지 않는다.
   - 없으면 아래 블록과 파일 경로를 사용자에게 그대로 보여주고, 그 파일 끝에 넣어도 되는지 묻는다. 이 블록이 있어야 기능을 완성할 때 classmate가 자동으로 실행되고, `.classmate/`가 켜진 프로젝트에서만 동작한다고 설명한다.
     - 동의하면 파일이 있을 때는 기존 내용을 그대로 두고 끝에 빈 줄 하나를 둔 뒤 블록을 덧붙인다. 파일이 없으면 폴더까지 만들고 블록만 쓴다.
     - 거절하면 자동 실행 없이 classmate를 직접 불러서만 쓸 수 있다고 알리고 다음 단계로 간다.

   ```
   <!-- classmate:start -->
   현재 프로젝트에 `.classmate/config.json`이 있고 enabled가 true이면,
   기능 하나를 완성했을 때 classmate 스킬을 실행해 설명과 이해도 퀴즈를 제공한다.
   <!-- classmate:end -->
   ```

2. **난이도 묻기.** 위 난이도 표를 보여주고 고르게 한다. 기본값은 `.classmate/config.json`이 있으면 그 난이도, 없으면 `중급`이다.
3. **`.classmate/` 준비.**
   - `.classmate/config.json`을 `{"enabled": true, "level": "<고른 난이도>"}`로 쓴다.
   - `.classmate/.gitignore`가 없으면 내용이 `*` 한 줄인 파일로 만든다. 이 파일 덕분에 학습 기록이 커밋되지 않는다.
4. **알리기.** 고른 난이도, 기능을 완성하면 설명과 퀴즈가 나온다는 것, 퀴즈는 언제든 '나중에'를 고를 수 있다는 것, `off`·`level`·`review` 명령을 짧게 알린다.

## 끄기 (`off`)

- `.classmate/config.json`이 없으면 이 프로젝트에서 classmate를 켠 적이 없다고 알리고 끝낸다.
- 있으면 `enabled`만 `false`로 바꾼다. 다른 값은 그대로 둔다.
- `.classmate/` 폴더, 학습 기록, 전역 지침 블록은 지우지 않는다.
- 학습 기록은 남아 있고, 다시 켜려면 `on`이라고 알린다.

## 난이도 바꾸기 (`level`)

- `.classmate/config.json`이 없으면 먼저 `on`을 하라고 알리고 끝낸다.
- 인자가 `입문`, `중급`, `고급` 중 하나면 config의 `level`만 바꾸고 알린다.
- 아니면 난이도 표를 보여주고 고르게 한다.
